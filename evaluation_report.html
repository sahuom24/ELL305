3 Technical Review of Revisions & Empirical Corroboration

Dual-Workload Empirical Results (Section 7):
The authors' decision to evaluate both isolation micro-benchmarks and procedural macro-workloads provides complete scientific transparency:

  • Workload A (Isolation Suite, 155,000 branches): Confirmed theoretical corner cases. Bimodal counters fail on alternating patterns (19.04% miss rate). PAg and SAg eliminate pattern misses (94.06% accuracy). The Alpha 21264 tournament engine achieves 94.66% accuracy, cutting mispredictions by 71.94%.
  • Workload B (SPECint-Style Procedural Trace, 709,980 branches): Evaluated multi-procedure integer control flow (lexer/parser state machines, token classifiers, hash table bucket traversal, quicksort pivot partitioning, and return guards). PAg's accuracy drops to 85.21% due to inter-procedural path blindness, while Gshare achieves 92.88% by capturing cross-basic-block history. The Alpha 21264 tournament engine dominates both with 92.93% accuracy (cutting mispredictions by 74.34%).

Microarchitectural Front-End Decoupling (Section 9):
The revised paper correctly details how modern processors overcome the two-cycle local lookup penalty: a single-cycle Next-Line Predictor (μBTB) delivers branch targets with zero bubble latency, while the complex tournament/TAGE predictor runs decoupled across two cycles, overriding the fetch queue only on divergence.

4 Viva Voce / Oral Defense Model Solutions & Faculty Answers

The authors are fully prepared for defense on all microarchitectural questions:

Question 1: Speculative Updates & Checkpoint Recovery
Model Faculty Answer: The Alpha 21264 updates its 12-bit GHR speculatively at instruction fetch so consecutive in-flight branches see recent history. To recover from mispredictions, the processor maintains an array of 32 branch checkpoints (Scheckpoint = 704 bits). Upon a pipeline flush, the GHR and LHT pointers are restored from the checkpoint within 1 cycle, eliminating stall bubbles.
Question 2: Synthetic vs. Real-World Benchmarks
Model Faculty Answer: Synthetic micro-benchmarks serve as an isolation test bench to cleanly verify theoretical failure modes (e.g. 2-bit hysteresis on loop exits, alternating sequence learning). Real-world SPECint workloads test cross-procedural path entropy and working-set aliasing across hundreds of active branch sites. Evaluating both proves theoretical mechanisms and macro-workload robustness.
Question 3: Set-Associative Branch History (SxX) Formulation
Model Faculty Answer: In SAg, branches are hashed into S = B/K sets (Set Index = (PC >> 2) mod S), with each set sharing an h-bit BHR. The state cost is SSAg = (B/K)h + 2 · 2h. This compresses first-level BHR state by a factor of K relative to PAg, trading minor intra-set aliasing for significant silicon savings.
Question 4: Pipeline Fetch Latency & Decoupled Predictors
Model Faculty Answer: The two serialized table lookups of the local predictor (PC → LHT → PHT) cannot fit in a 1-cycle fetch stage at >1 GHz. Processors solve this via front-end decoupling: a single-cycle Next-Line Predictor (μBTB) drives bubble-free instruction fetch in Cycle 1, while the main tournament predictor operates pipelined over 2 cycles, overriding the μBTB on disagreement.
Question 5: Silicon Scaling of the PAp Architecture
Model Faculty Answer: For B branches and h history bits, PAp requires SPAp = Bh + 2B · 2h bits. For B = 4096 and h = 12, PAp requires >33 Megabits of SRAM—an unroutable silicon footprint. Microprocessors therefore employ shared-PHT (PAg/SAg/gshare) designs to constrain state within tens of kilobits.
